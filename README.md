# PyLens

**See what your Python code is really doing.**

PyLens is an open-source Python performance monitoring tool designed to analyze script execution, track system resource consumption, identify performance bottlenecks, and generate detailed execution reports.

Built with a focus on simplicity, transparency, and developer control, PyLens aims to help developers understand how their Python applications behave during execution.

## Key Features

- **Execution Monitoring:** Track Python script execution.
- **Resource Tracking:** Monitor CPU and RAM consumption.
- **Performance Analysis:** Identify potential bottlenecks and performance issues.
- **Execution Reports:** Generate detailed reports about monitored processes.
- **Execution History:** Store and review previous executions.
- **Logging System:** Record events, warnings, and critical issues.
- **Configurable Limits:** Set execution time and memory limits.
- **Local Database:** Store monitoring data locally.

## Project Goals

PyLens aims to provide developers with a practical way to understand application performance without relying on external monitoring services or AI-based analysis.

## Current Development

PyLens is under active development.

The initial release is planned for Linux, with Python script monitoring as its primary focus.
